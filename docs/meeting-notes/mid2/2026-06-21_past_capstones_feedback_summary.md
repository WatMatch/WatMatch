# Past Capstones Feedback Summary - 2026-06-21

## Source

Anonymized feedback submitted through the deployed past-capstones archive.

## Submitted Product Feedback

- The archive would benefit from more features beyond read-only browsing.
- Add dark mode.
- Add project type or theme filters, such as Applied AI, Systems Software, Health, robotics, semiconductors, RF, ML, and other engineering niches.
- Consider using historical projects to build a knowledge graph or theme-cluster visualization.
- Show team member profiles, LinkedIn links, current members, and experience context so students can understand whether a team has the background to execute a project.
- Show presentation photos, documentation, supporting artifacts, or group photos when available.
- Show currently available projects that students can join.

## Feedback Themes

- Students want stronger filtering by project type, technical area, department, skill, and theme.
- Students want the archive to connect to current opportunities, not only historical browsing.
- Students want richer team/profile context before deciding whether to join or follow a project.
- Students want supporting artifacts for past projects where available.
- A knowledge graph or cluster view is interesting, but it is a later research/visualization feature rather than core Mid 2 scope.

## Product Implications

### Mid 2 Relevant

- Add stronger student profile creation and profile browsing.
- Support current capstone/opportunity discovery, not only historical browsing.
- Support shortlisting/bookmarking so students can save interesting past and current projects.
- Improve filtering around department, project type, skills, and engineering niche.

### Later/Future Relevant

- Dark mode.
- Rich media attachments for completed capstones.
- Public team/profile display rules.
- Knowledge graph or cluster visualization across capstone themes.

- [ ] Use feedback to justify student profiles and current-project marketplace exploration in Mid 2.
- [ ] Track project-type/theme filters as a high-value future improvement.
- [ ] Avoid overbuilding knowledge graph functionality before the core marketplace flow works.
